Datos de gimnasios de escalada (ODbL)

ES. Esta carpeta contiene la base de datos derivada de OpenStreetMap que usa la app Boulder Tracker (gimnasios de escalada de 44 países; 2435 registros). Se ofrece bajo la Licencia de Base de Datos Abierta (ODbL) 1.0. Cualquiera puede copiarla, distribuirla y adaptarla manteniendo la atribución y la misma licencia para la base de datos derivada.

EN. This folder contains the database derived from OpenStreetMap that the Boulder Tracker app uses (climbing gyms in 44 countries; 2435 records). It is offered under the Open Database License (ODbL) 1.0. Anyone may copy, distribute and adapt it, keeping the attribution and the same license for the derived database.

Atribución / Attribution: © colaboradores de OpenStreetMap / OpenStreetMap contributors. Extraído el 2026-10-03 con la API Overpass y filtrado (se descartan elementos que no son gimnasios de escalada) / extracted on 2026-10-03 using the Overpass API and filtered.

Campos / Fields: id (osm-nXXXX / wXXXX / rXXXX), n nombre/name, r región/region, c ciudad/city, a dirección/address, w web, i Instagram, p teléfono comercial/business phone, h horario/hours, la/lo latitud/longitud. No se incluyen correos electrónicos / email addresses are not included.
